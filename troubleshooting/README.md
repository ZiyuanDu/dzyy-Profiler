# Troubleshooting

Solutions to errors encountered while running the tutorials. 

> ***Run all commands from the project root unless a guide states otherwise.***


## Known issues

| Error | Cause | Guide |
| --- | --- | --- |
| `nvcc fatal: Value 'sm_120a' is not defined for option 'gpu-architecture'` | The selected CUDA compiler does not support the GPU architecture. | [CUDA compilation fails on RTX 5090](cuda-unsupported-gpu-architecture.md) |
